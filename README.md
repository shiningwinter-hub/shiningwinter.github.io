# 우리가 만든 세상, 우리가 채우는 색깔

## 배포 (GitHub Pages)
1. GitHub에서 새 공개 저장소를 생성합니다. 예: `our-colorbook`.
2. ZIP을 풀고 `index.html`, `style.css`, `app.js`, `artworks.js`, `.nojekyll`을 저장소 최상위에 업로드하고 Commit합니다. ZIP 자체를 업로드하지 않습니다.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save.
4. Pages에 표시된 HTTPS 주소에 접속합니다. 주소 예시: `https://계정명.github.io/our-colorbook/`.
5. 처음에는 예시 공룡 한 장이 표시됩니다.

## 학생 작품 등록 및 배포
- 상단 교사 → 주제/난이도/민감도 선택 → 원본 파일 여러 장 선택 → 자동 선화 만들기.
- 미리보기 확인 후 필요하면 민감도 조절 및 재변환. 선이 끊기거나 너무 복잡하면 외부 AI로 만든 선화를 별도 파일로 교체할 수 있습니다. 원본과 선화는 같은 구도·비율을 권장합니다.
- 각 작품의 제목을 수정하고 등록합니다. 학생 실명 대신 별명 또는 작품명 권장.
- artworks.js 저장 → GitHub 저장소에서 기존 artworks.js를 교체하여 Commit. Pages 반영 후 새로고침. 모든 학생은 같은 주소로 작품을 볼 수 있습니다.
- 로컬 등록만으로 학생 기기에 공유되지 않습니다. 기존 배포 파일은 백업해 두세요.
- 교사 메뉴에서 주소를 복사하고 원하는 QR코드 생성기로 QR을 만들어 인쇄할 수 있습니다.
- 인쇄용 컬러링북 버튼은 새 탭에서 A4 인쇄 창을 엽니다. PDF로 저장할 수도 있습니다.

## 작동 방식과 제한
- 자동 선화는 브라우저에서 색상 경계 검출 및 형태학적 연결/굵기 보정을 수행합니다. 생성형 AI가 아니며 API 키나 서버가 없습니다. 복잡한 사진/그라데이션은 결과가 좋지 않을 수 있고 폐곡선이 아닌 영역은 색이 번질 수 있습니다. 배포 전에 반드시 직접 채우기 테스트를 하세요.
- 이미지 최대 긴 변 1100px. 이미지가 많으면 artworks.js가 커지므로 소규모 작품집에 적합합니다. 대규모 배포는 이미지 파일 분리 권장.
- 색칠 상태와 교사 등록은 브라우저 IndexedDB에 저장됩니다. 기기·브라우저 간 동기화되지 않으며 데이터 삭제 시 사라질 수 있습니다. PNG 별도 저장 권장.
- 원본 색 기능은 각 영역의 원본 평균 색상을 채우는 방식입니다. 원본 이미지와 완전히 일치하지 않습니다.
- 자유 색칠은 검은 선을 보존하지만 한 번의 붓질이 여러 영역에 걸칠 수 있습니다. 채우기는 연결된 영역만 칠합니다.
- 교사 메뉴는 편의 기능으로 비밀번호 인증이 아닙니다. GitHub 공개 저장소와 Pages는 공개 배포입니다. 학생/보호자 및 기관의 공개 동의를 확인하고 식별 가능한 정보는 제거하세요. QR은 접근 제한이 아닙니다.
- 효과음/음악은 감각 부담을 줄이기 위해 넣지 않았습니다. 완성 축하 애니메이션은 기기에서 동작 감소 설정 시 표시하지 않습니다.
- 오프라인 실행은 로컬 웹 서버 권장: 폴더에서 `python -m http.server 8000`, 브라우저에서 `http://localhost:8000` 접속.
